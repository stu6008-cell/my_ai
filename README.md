# 미니 AI

파이썬 **표준 라이브러리만으로** 만든 한국어 대화 프로그램.
외부 API도, Ollama도, `pip install` 도 필요 없다. `python3` 만 있으면 돌아간다.

```
$ python3 chat.py
너 > 안녕
미니 > 반가워. 오늘 어땠어?

너 > 12 * (3+4) 는 뭐야
미니 > 12 * (3+4) = 84

너 > 내 이름은 지훈이야
미니 > 반가워 지훈! 이제 지훈라고 부를게.

너 > 좋아하는 색이 뭐야
미니 > 처음 듣는 얘기야. 뭐라고 답하면 좋을지 가르쳐줄래? (/배워 좋아하는 색이 뭐야 | 답변)

너 > /배워 좋아하는 색이 뭐야 | 나는 파란색이 좋아
미니 > 새로 배웠어!

너 > 좋아하는 색깔이 뭐야?
미니 > 나는 파란색이 좋아
```

## 실행

```bash
python3 chat.py              # 대화 시작
python3 chat.py -s           # 답변마다 근거와 유사도 점수 표시
python3 chat.py --say "안녕"  # 한 마디만 주고받고 종료
python3 -m mini_ai           # 패키지로 실행해도 동일
python3 -m unittest discover -s tests   # 테스트
```

옵션: `-m/--memory` 기억 파일 경로, `-k/--knowledge` 지식 파일 경로.

## 명령어

| 명령 | 설명 |
|---|---|
| `/도움말` | 명령어 목록 |
| `/배워 질문 \| 답변` | 새 문답 가르치기 |
| `/배워` | 방금 내가 한 말에 대한 답을 대화형으로 가르치기 |
| `/기억` | 외운 것 전부 보기 |
| `/잊어 [키워드]` | 특정 기억 삭제 (키워드 없으면 전부) |
| `/저장` | 기억을 파일로 저장 (종료 시 자동 저장) |
| `/상상 [단어]` | 배운 문장들로 새 문장 지어내기 |
| `/디버그 문장` | 유사도 후보와 점수 확인 |
| `/종료` | 저장하고 종료 |

## 어떻게 동작하나

거대 언어모델이 아니라, 고전적인 정보검색(IR) 방식이다.

```
입력
 └→ 1. 규칙 스킬        계산기 / 시간·날짜 / 기억 / 주사위 / 선택
 └→ 2. TF-IDF 유사도    질문을 벡터로 만들어 아는 문장들과 코사인 비교
 └→ 3. 판단             0.30 이상이면 답변, 0.13~0.30이면 되묻기, 미만이면 학습 유도
```

### 1. 토큰화 (`tokenizer.py`)
형태소 분석기 없이 한국어를 다루기 위해 세 가지를 섞는다.

- **원형 단어**: `반갑습니다`
- **어간 근사**: 가장 긴 조사/어미 하나를 규칙으로 제거 → `반갑`
- **음절 2-gram**: `반갑`, `갑습`, `습니`, `니다`

덕분에 `좋아하는 색이 뭐야` 로 배운 걸 `좋아하는 색깔이 뭐야?` 로 물어도 찾아낸다.

### 2. TF-IDF 색인 (`vectorizer.py`)
문서마다 정규화 TF × smoothed IDF 벡터를 만들고 코사인 유사도로 비교한다.
여기에 두 가지 보정이 들어가 있다.

- **미등록 단어 처리**: 색인에 없는 단어를 버리면 모르는 질문일수록
  남은 흔한 단어끼리 100% 일치해버린다 (`양자역학이 뭐야` → `너는 뭐야`).
  그래서 미등록 단어에 최대 IDF를 주고 벡터에 남긴다.
- **커버리지 가중**: `코사인 × √(설명된 질의 비율)`. 짧은 문서가
  무조건 유리해지는 편향을 줄인다.

### 3. 마르코프 생성 (`markov.py`)
학습한 모든 문장으로 2차 마르코프 체인을 만든다. 막다른 상태에 빠지면
1차 상태로 후퇴(backoff)해서 이어간다. `/상상` 에서 쓴다.

### 4. 학습과 기억 (`brain.py`)
가르친 문답과 기억한 사실은 `mini_ai/data/memory.json` 에 저장되고,
학습 즉시 색인을 다시 만들기 때문에 재시작 없이 바로 반영된다.
저장은 임시 파일에 쓴 뒤 `os.replace` 로 교체해서, 도중에 죽어도 기존 기억이 남는다.

## 구조

```
chat.py                    실행 진입점
mini_ai/
  tokenizer.py             한국어 토큰화 (어간 + 음절 n-gram)
  vectorizer.py            TF-IDF 색인과 코사인 검색
  markov.py                마르코프 체인 문장 생성
  skills.py                규칙 기반 능력 (계산·시간·기억·잡기술)
  brain.py                 대화 엔진, 학습, 기억
  cli.py                   터미널 루프와 슬래시 명령어
  data/knowledge.json      기본 지식 (의도 - 패턴 - 응답)
  data/memory.json         학습한 내용 (자동 생성)
tests/test_mini_ai.py      unittest 32개
```

## 지식 추가하기

`mini_ai/data/knowledge.json` 을 직접 편집해도 된다.

```json
{
  "name": "커피",
  "patterns": ["커피 좋아해", "카페인 어때", "아메리카노 마실까"],
  "responses": ["나는 못 마시지만 구경은 좋아해.", "오늘은 디카페인 어때?"]
}
```

`patterns` 는 사용자가 할 법한 말, `responses` 중 하나가 무작위로 선택된다.

## 계산기 안전성

`eval()` 을 쓰지 않는다. `ast.parse` 로 구문 트리를 만든 뒤
사칙연산·거듭제곱·단항 부호 노드만 직접 계산하므로,
`__import__('os').system('rm -rf /')` 같은 입력은 실행되지 않고 거부된다.

## 한계

솔직하게 적자면 — 이건 언어를 이해하지 못한다. 배운 문장과 비슷한지만 잰다.
새로운 지식을 스스로 만들어내지 못하고, 문맥을 두 턴 이상 기억하지 않으며,
`/상상` 결과는 대체로 말이 안 된다. 대신 전부 읽을 수 있는 코드이고,
인터넷 없이 완전히 오프라인으로 돈다.
