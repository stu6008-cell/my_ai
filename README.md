# 미니 AI

파이썬 **표준 라이브러리만으로** 만든 한국어 대화 프로그램.
브라우저용 단일 HTML 버전도 같이 들어 있다 (`web/index.html`).
외부 API도, Ollama도, `pip install` 도 필요 없다. `python3` 만 있으면 돌아간다.

핵심 정책은 하나다. **내가 파일에 넣은 정보만 학습한다.**
내장 잡담 지식은 꺼져 있고, 대화로는 아무것도 배우지 않는다.
원본 파일이 유일한 진실이라, 파일에서 지우면 다음 새로고침에 잊는다.

```
$ python3 chat.py
너 > 출근 몇시에 해
미니 > 아직 배운 게 없어. 원본 파일에 정보를 적고 '/새로고침' 해줘.
         mini_ai/data/source.txt
```

`mini_ai/data/source.txt` 를 열어서 적는다.

```
좋아하는 음식: 마라탕
회사 출근 시간: 오전 9시 30분
Q: 우리 강아지 이름이 뭐야
A: 콩이야, 올해 3살
주말에 뭐 할까 | 한강 가서 자전거 타자
파이썬은 배우기 쉬운 프로그래밍 언어이다
```

```
너 > /새로고침
미니 > 다시 학습했어. 사실 3개 · 문답 14개 · 문장 1개

너 > 출근 몇시에 해
미니 > 오전 9시 30분

너 > 내가 좋아하는 음식 알려줘
미니 > 마라탕

너 > 강아지 이름
미니 > 콩이야, 올해 3살

너 > 안녕
미니 > '안녕' 은(는) 내 파일에 없는 내용이야. 원본 파일에 적어주면 배울게.
```

`출근 몇시에 해` 는 파일 어디에도 없는 문장이다. 답을 기준으로 질문 변형들을
한 묶음으로 학습한 분류기가 잡아낸 것이다.

## 실행

```bash
python3 chat.py                      # 대화 시작
python3 chat.py -s                   # 답변 근거와 유사도 점수 표시
python3 chat.py -f 내정보.txt         # 다른 파일을 원본으로 사용
python3 chat.py --say "출근 몇시"     # 한 마디만 주고받고 종료
python3 -m unittest discover -s tests # 테스트 64개
```

| 옵션 | 설명 |
|---|---|
| `-f, --source` | 학습할 원본 파일 (기본 `mini_ai/data/source.txt`) |
| `-d, --dataset` | 정리된 데이터셋 JSON 경로 |
| `-m, --memory` | 통계·기억 파일 경로 |
| `-s, --score` | 응답 근거와 점수 표시 |
| `--with-defaults` | 내장 잡담 지식도 함께 사용 |
| `--chat-learning` | 대화로도 배우게 허용 (기본은 금지) |

## 명령어

| 명령 | 설명 |
|---|---|
| `/새로고침` | 원본 파일을 다시 읽어 학습 |
| `/데이터` | 지금 학습한 내용 전부 보기 |
| `/원본` | 원본 파일 경로와 작성법 |
| `/학습 파일경로` | 다른 파일을 원본으로 삼아 학습 |
| `/학습현황` | 무엇을 얼마나 배웠는지 통계 |
| `/상상 [단어]` | 배운 문장들로 새 문장 지어내기 |
| `/디버그 문장` | 유사도 후보와 분류기 판단 확인 |
| `/도움말` `/종료` | |

`--chat-learning` 을 켰을 때만 `/배워 질문 | 답변`, `/좋아`, `/별로` 가 동작한다.

## 원본 파일 작성법

한 파일에 섞어 써도 된다.

| 형식 | 예시 | 해석 |
|---|---|---|
| `키: 값` | `좋아하는 음식: 마라탕` | 사실 + 질문 4가지 자동 생성 |
| `Q:` / `A:` | `Q: 강아지 이름`<br>`A: 콩이야` | 명시적 문답 |
| `질문 \| 답변` | `주말에 뭐 할까 \| 한강 가자` | 한 줄 문답 |
| `X는 Y이다` | `파이썬은 쉬운 언어이다` | 사실 + 자동 문답 |
| 그 외 문장 | `오늘은 비가 왔다` | 말투 학습용 말뭉치 |
| `#` 로 시작 | `# 메모` | 주석 |

이미 정리된 JSON 을 그대로 넣어도 된다.

```json
{ "facts": {"수도": "서울"}, "pairs": [{"question": "인구", "answer": "5천만"}] }
```

`키: 값` 하나를 넣으면 조사까지 맞춰 질문 4개를 만든다 —
`수도 뭐야` / `수도가 뭐야` / `수도 알려줘` / `수도에 대해 설명해줘`.
받침 유무를 보고 `이/가` 를 고르기 때문에 `이름이 뭐야`, `수도가 뭐야` 가 된다.

## 어떻게 동작하나

LLM이 아니라 고전적인 정보검색(IR) 방식이다.

```
원본 파일 (source.txt)
     │  ingest.compile_source  - 파싱해서 구조화
     ▼
데이터셋 (dataset.json)  ← 사람이 직접 열어봐도 읽히는 형태
     │  reindex
     ├─→ TF-IDF 색인      질문 문장들
     ├─→ 나이브 베이즈     답변 기준으로 묶은 라벨
     └─→ 마르코프 체인     모든 문장

입력
 └→ 1. TF-IDF 유사도    0.30 이상이면 바로 답변
 └→ 2. 규칙 스킬        계산기 / 시계 (내 데이터가 우선한다)
 └→ 3. 분류기           0.80 이상 확신하면 답변
 └→ 4. 되묻기 / 안내    0.13~0.30 이면 "혹시 이 얘기야?"
```

### 토큰화 (`tokenizer.py`)
형태소 분석기 없이 한국어를 다루려고 세 가지를 섞는다.

- **원형 단어**: `반갑습니다`
- **어간 근사**: 가장 긴 조사/어미 하나를 규칙으로 제거 → `반갑`
- **음절 2-gram**: `반갑`, `갑습`, `습니`, `니다`

덕분에 `좋아하는 음식: 마라탕` 하나로 `내가 좋아하는 음식 알려줘` 까지 잡힌다.

### TF-IDF 색인 (`vectorizer.py`)
정규화 TF × smoothed IDF 벡터를 코사인 유사도로 비교한다. 보정이 두 개 있다.

- **미등록 단어 처리**: 색인에 없는 단어를 버리면 모르는 질문일수록
  남은 흔한 단어끼리 100% 일치해버린다 (`양자역학이 뭐야` → `너는 뭐야`).
  그래서 미등록 단어에 최대 IDF를 주고 벡터에 남긴다.
- **커버리지 가중**: `코사인 × (설명된 질의 비율 ^ 0.25)`.
  지수는 라벨링한 문장으로 0 / 0.25 / 0.5 를 비교해서 골랐다.
  0이면 `주식 전망 알려줘` 가 파이썬 설명에 붙고, 0.5면 정상적인 의역까지 떨어진다.

### 나이브 베이즈 분류기 (`learner.py`)
**같은 답을 가리키는 질문들을 한 라벨로 묶어** 학습한다.
`회사 출근 시간: 오전 9시 30분` 하나에서 질문 4개가 생기고 전부 같은 라벨이 되므로,
파일에 없는 `출근 몇시에 해` 도 그 라벨로 분류된다.

어휘에 없는 토큰은 세지 않고, 아는 토큰이 2개 미만이거나 1·2위 확률 차가
0.08 미만이면 판단을 포기한다. 모르는 문장에 억지로 라벨을 붙이지 않기 위한 장치다.

### 마르코프 생성 (`markov.py`)
학습한 문장으로 2차 마르코프 체인을 만들고, 막다른 상태에선 1차로 후퇴한다. `/상상` 에서 쓴다.

## 왜 대화로 안 배우게 막았나

대화 학습 경로는 코드에 그대로 있지만 `learn_from_chat` 스위치 하나로 전부 막혀 있다.
막힌 경로는 이렇다.

- `/배워` 로 문답 가르치기 → `PermissionError`
- `내 이름은 ○○` 같은 사실 저장 → 거절하고 파일에 적으라고 안내
- 되묻기에 "응" 했을 때 그 표현 흡수 → 답만 하고 배우지는 않음
- 확신한 매칭을 분류기에 되먹이는 자기지도 학습 → 중단
- `/좋아` `/별로` 피드백 반영 → 무시

`--chat-learning` 을 주면 전부 되살아난다. 그때만 되묻기가 학습으로 이어진다.

```
너 > 잘 지내셨어요
미니 > 혹시 '안녕하세요' 얘기야? 맞으면 '응' 이라고 해줘.
너 > 응
미니 > 반가워. 오늘 어땠어?
       (그리고 '잘 지내셨어요' 도 같은 뜻으로 외웠어.)
```


## 웹 버전 (설치 없이 브라우저에서)

`web/index.html` 을 더블클릭하면 끝이다. 서버도, 빌드도, 인터넷도 필요 없다.
파이썬판과 같은 알고리즘을 그대로 옮긴 단일 HTML 파일이고, 외부 스크립트를
하나도 불러오지 않는다.

1. 페이지를 연다
2. `파일 열기` 를 누르거나, 창에 원본 파일을 **끌어다 놓는다**
3. 물어본다

파일을 고쳤으면 다시 열면 된다. Chrome 계열에서는 File System Access API 로
파일 핸들을 붙잡아 두기 때문에 `새로고침` 버튼 한 번이면 다시 읽는다.

학습한 데이터셋은 `localStorage` 에 남으므로 페이지를 닫았다 열어도 유지되고,
`기억 지우기` 로 전부 지운다. 대화로는 배우지 않는 정책도 그대로다.

### 파이썬판과 달라진 세 곳

| 부분 | 파이썬 | 웹 | 이유 |
|---|---|---|---|
| 계산기 | `ast.parse` 로 노드 검사 | 재귀 하강 파서 직접 구현 | JS 에는 `ast` 가 없고 `eval()` 은 쓰지 않는다 |
| 원본 읽기 | 경로에서 직접 읽기 | 파일 선택 · 드래그앤드롭 | 브라우저는 파일 시스템을 뒤질 수 없다 |
| 저장 | `dataset.json` | `localStorage` | 디스크에 쓸 수 없다 |

나머지 - 토큰화, TF-IDF, 나이브 베이즈, 마르코프, 원본 파서 - 는 1:1로 대응된다.
소스 안에 `브라우저에서 달라진 곳 (n/3)` 주석으로 세 지점을 표시해뒀다.

### 검증

브라우저 밖에서는 확인할 수 없는 것들이라 실제 Chromium 을 CDP 로 띄워 확인했다:
페이지 로드와 콘솔 오류, 파일 입력과 드래그앤드롭, 명령어, `localStorage` 저장과
복구, 그리고 **사용자 입력과 파일 내용이 HTML 로 해석되지 않는지**. 화면에 찍히는
문자열은 전부 `textContent` 로만 들어가므로 `<script>` 가 섞인 파일을 떨어뜨려도
그냥 글자로 보인다.

## 구조

```
chat.py                    실행 진입점
web/index.html             웹 버전 (단일 파일, 의존성 0)
mini_ai/
  tokenizer.py             한국어 토큰화 (어간 + 음절 n-gram)
  vectorizer.py            TF-IDF 색인과 코사인 검색
  ingest.py                자유 텍스트 → 구조화 JSON 컴파일
  learner.py               나이브 베이즈 분류기, 응답 가중치
  markov.py                마르코프 체인 문장 생성
  skills.py                계산기·시계 (기억이 아니라 계산)
  brain.py                 대화 엔진, 학습 정책
  cli.py                   터미널 루프와 슬래시 명령어
  data/source.txt          내가 편집하는 원본 (여기에 적는다)
  data/dataset.json        컴파일된 데이터셋 (자동 생성)
  data/knowledge.json      내장 잡담 지식 (--with-defaults 일 때만)
  data/memory.json         통계와 대화 학습 결과 (자동 생성)
tests/test_mini_ai.py      unittest 64개
```

## 계산기 안전성

`eval()` 을 쓰지 않는다. `ast.parse` 로 구문 트리를 만든 뒤
사칙연산·거듭제곱·단항 부호 노드만 직접 계산하므로,
`__import__('os').system('rm -rf /')` 같은 입력은 실행되지 않고 거부된다.

## 한계

솔직하게 적자면 — 이건 언어를 이해하지 못한다. 파일에 적힌 문장과 비슷한지만 잰다.
파일에 없는 걸 추론하지 못하고, 문맥을 두 턴 이상 기억하지 않으며,
`/상상` 결과는 대체로 말이 안 된다. 대신 아는 것의 출처가 파일 하나로 명확하고,
전부 읽을 수 있는 코드이며, 인터넷 없이 완전히 오프라인으로 돈다.
